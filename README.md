A step-by-step guide to creating a new Laravel 13 project with the Vue starter kit (Inertia + Vue 3 + Tailwind + shadcn-vue) running on DDEV.

Host requirements: docker engine and ddev

No host-side PHP, Composer, or Laravel installer required - everything runs inside the DDEV container.

> **Quick start**: Run `./quick-start.sh <project-name>` to automate all steps below. Requires Docker and DDEV.

References:
- [Laravel Starter Kits](https://laravel.com/docs/13.x/starter-kits)
- [DDEV Vite Integration](https://docs.ddev.com/en/stable/users/usage/vite/#laravel)

> **Note**

> This guide uses `my-vue-site` as an example name.

## Step 1: Scaffold the DDEV project

```bash
mkdir my-vue-site && cd my-vue-site
ddev config --project-type=laravel --docroot=public
```

Edit `.ddev/config.yaml` to add the Vite port mapping:

```yaml
web_extra_exposed_ports:
  - name: vite
    container_port: 5173
    http_port: 5172
    https_port: 5173
```

Start the development environment:

```bash
ddev start
```

## Step 2: Install the Laravel CLI inside DDEV

The Vue starter kit is built into the Laravel CLI - it cannot be added to an existing project via Composer. Install the CLI inside the container:

```bash
ddev composer global require laravel/installer
```

## Step 3: Create the Laravel project with the Vue starter kit

The `laravel new` command requires a named directory (`.` won't work with `--force`). Create in a subdirectory, then move files up to the project root:

```bash
ddev exec \$HOME/.composer/vendor/bin/laravel new my-vue-site --vue --npm
ddev exec "cp -r my-vue-site/. /var/www/html/ && rm -rf my-vue-site"
```

This creates the full project structure including:
- Inertia + Vue 3 frontend scaffolding
- Authentication routes, controllers, and Vue pages (login, register, dashboard, etc.)
- TypeScript, Tailwind CSS, shadcn-vue component library
- Laravel Fortify for backend authentication
- `composer install` and `npm install` run automatically

The `.env` file created points `APP_URL` at `http://localhost:8000` which was valid only for the use of the laravel command that created the site. This needs to be updated with the actual URL for the project:

```bash
ddev exec "sed -i 's|APP_URL=http://localhost:8000|APP_URL=https://my-vue-site.ddev.site|' .env"
```

## Step 4: Configure the database

The default `.env` generated by `laravel new` uses SQLite. Update it for DDEV's MariaDB:

```bash
ddev exec sed -i \
  -e 's/DB_CONNECTION=sqlite/DB_CONNECTION=mariadb/' \
  -e 's/# DB_HOST=127.0.0.1/DB_HOST=db/' \
  -e 's/# DB_PORT=3306/DB_PORT=3306/' \
  -e 's/# DB_DATABASE=laravel/DB_DATABASE=db/' \
  -e 's/# DB_USERNAME=root/DB_USERNAME=db/' \
  -e 's/# DB_PASSWORD=/DB_PASSWORD=db/' \
  .env
```

Run the migrations:

```bash
ddev artisan migrate
```

## Step 5: Configure Vite for DDEV

The starter kit generates `vite.config.ts`. Add the DDEV-specific server settings:

```ts
import inertia from '@inertiajs/vite';
import { wayfinder } from '@laravel/vite-plugin-wayfinder';
import tailwindcss from '@tailwindcss/vite';
import vue from '@vitejs/plugin-vue';
import laravel from 'laravel-vite-plugin';
import { bunny } from 'laravel-vite-plugin/fonts';
import { defineConfig } from 'vite';

export default defineConfig({
    plugins: [
        laravel({
            input: ['resources/css/app.css', 'resources/js/app.ts'],
            refresh: true,
            fonts: [
                bunny('Instrument Sans', {
                    weights: [400, 500, 600],
                }),
            ],
        }),
        inertia(),
        tailwindcss(),
        vue({
            template: {
                transformAssetUrls: {
                    base: null,
                    includeAbsolute: false,
                },
            },
        }),
        wayfinder({
            formVariants: true,
        }),
    ],
    server: {
        host: "0.0.0.0",
        port: 5173,
        strictPort: true,
        origin: `${process.env.DDEV_PRIMARY_URL_WITHOUT_PORT}:5173`,
        allowedHosts: ['.ddev.site'],
        cors: {
            origin: /https?:\/\/([A-Za-z0-9\-\.]+)?(\.ddev\.site)(?::\d+)?$/,
        },
    },
});
```

`allowedHosts` is required for Vite 8+ - it blocks requests with unknown `Host` headers, but DDEV's proxy forwards the real domain, not `localhost`.

## Step 6: Build and test

```bash
ddev npm run build
ddev composer run dev
```

Visit the site at `https://my-vue-site.ddev.site`. You should see the Laravel welcome page with authentication - login, register, and dashboard routes are all functional.

## Troubleshooting

- **Firefox cert errors**: Run `mkcert -install` on the host, then import the CA into Firefox (`about:config` → `security.enterprise_roots.enabled = true`). See the [DDEV browser config guide](https://docs.ddev.com/en/stable/users/install/configuring-browsers/).
- **Vite returns 403**: Make sure `allowedHosts` includes `'.ddev.site'`.
- **Assets not loading**: Check `ddev exec cat public/hot` - it should show `https://my-vue-site.ddev.site:5173`.
- **Bad Gateway**: Restart Vite with `ddev npm run dev` or verify the port mapping in `.ddev/config.yaml`.
- **`laravel` command not found**: Use `\$HOME/.composer/vendor/bin/laravel`, or add it to PATH: `ddev exec "export PATH=\$PATH:\$HOME/.composer/vendor/bin"`.
